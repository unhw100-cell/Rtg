# CURRENT_ARCHITECTURE — Аудит существующего проекта Rustgram

## 1. Обзор текущего состояния
Текущий **Rustgram** представляет собой нативное Android-приложение на **Kotlin + Jetpack Compose + Material Design 3** с облачной инфраструктурой **Firebase** (Authentication, Cloud Firestore с выделенной базой данных, App Check, Firebase AI Logic).

## 2. Полная карта существующих компонентов

| Файл / Компонент | Текущая роль | Что содержит из бизнес-логики | План переноса на Rust Core |
|---|---|---|---|
| `app/src/main/java/com/example/data/model/RustgramModels.kt` | Модели данных (`UserProfile`, `HandleEntry`, `ContactEntry`, `DraftEntry`, `CallLogEntry`, `ChatRoom`, `ChatMessage`, `GeminiBotPreset`) | Контракты доменных сущностей и значения по умолчанию | Переносится в `rustgram-common` и `rustgram-core` (`serde` + строгая типизация и лимиты) |
| `app/src/main/java/com/example/data/repository/MessagingRepository.kt` | Доступ к Firestore + вся доменная логика чатов, контактов, профилей, черновиков, логов звонков | `sanitizeId`, правила создания `@username`, валидация длин/лимитов, расчёт `chatId` (`saved_`, `dm_`), фильтрация/сортировка, toggle реакций (лимит 50), превью вложений, правила архивации | Логика валидации, санитизации, генерации ID/inviteCode, мутаций и сортировки переносится в `rustgram-profile`, `rustgram-contacts`, `rustgram-chat`, `rustgram-groups`, `rustgram-messaging`, `rustgram-storage`, `rustgram-sync`; Firestore SDK остаётся тонким транспортным адаптером |
| `app/src/main/java/com/example/data/repository/GeminiBotRepository.kt` | Интеграция с Gemini (`Firebase.ai`) + пресеты ботов | Список поддерживаемых моделей (`GeminiModels`), каталог `GeminiBotPresets`, выбор последних 24 сообщений истории, форматирование ролей `user`/`model`, обработка ошибок/таймаутов | Пресеты, каталог моделей, валидация промптов, построение контекста истории, очистка чанков и классификация ошибок переносятся в `rustgram-ai`; `Firebase.ai` SDK остаётся адаптером |
| `app/src/main/java/com/example/ui/viewmodel/MessengerViewModel.kt` | Управление состоянием UI, оркестрация сценариев | Логика `bootstrapUserWorkspace`, режимы reply/edit/forward/silent, пин сообщений, запуск AI-потока, фильтрация чатов | Доменная оркестрация (команды, фильтры `ChatFilter`, поиск, расчёт уведомлений) делегируется в Rust Core через `RustBridge` |
| `app/src/main/java/com/example/data/remote/FirestoreErrorHandler.kt` | Диагностика ошибок Firestore | Классификация `OperationType`, извлечение root cause, JSON-структурирование ошибки | Форматирование и классификация ошибок переносятся в `rustgram-common` (`ErrorClassifier`) |
| `app/src/main/java/com/example/data/remote/AppCheckInit.kt` | Инициализация Firebase App Check (Debug/reCAPTCHA) | Извлечение `FIREBASE_APPCHECK_DEBUG_TOKEN` и установка провайдера | Остаётся платформенным адаптером Android |
| `app/src/main/java/com/example/media/MediaAttachmentHelper.kt` | Выбор фото/файлов, сжатие Bitmap, запись/воспроизведение M4A | Именование вложений, лимиты размера (380KB/400KB Base64), оценка длительности и сводок | Политики вложений, валидация лимитов/типов/расширений и форматирование размеров переносятся в `rustgram-media`; `BitmapFactory`/`MediaRecorder`/`MediaPlayer` остаются в Kotlin |
| `app/src/main/java/com/example/ui/auth/AuthHelpers.kt`, `AuthScreen.kt` | Google Sign-In (`CredentialManager`) + AuthState | Проверка `default_web_client_id`, маппинг отмены и сессии | Проверки состояния сессии/UID переносятся в `rustgram-auth`; `CredentialManager` и `Firebase.auth` остаются в Kotlin |
| `app/src/main/java/com/example/ui/i18n/RustgramStrings.kt` | Локализация RU/EN (`StringsProvider`) | Словари UI для русского и английского языков | Локализационный реестр и системные сообщения переносятся в `rustgram-core` (`i18n`), Kotlin кэширует результат для Compose |
| `app/src/main/java/com/example/ui/screens/*`, `components/*`, `theme/*`, `RustgramApp.kt`, `MainActivity.kt` | Декларативный UI Jetpack Compose + M3 | Локальная фильтрация в `ChatsTabScreen`/`ConversationScreen` (выносится в Rust `rustgram-search`) | UI остаётся на Kotlin + Compose, фильтрация и поиск переносятся в Rust Core |
| `firestore.rules`, `firebase-blueprint.json`, `firestore.test.js` | Схема и Zero-Trust правила Cloud Firestore | Валидация полей на стороне сервера Firestore | Полностью сохраняются без изменений; правила Rust Core синхронизированы с ограничениями `firestore.rules` |
| `app/build.gradle.kts`, `settings.gradle.kts`, `AndroidManifest.xml`, `gradle/libs.versions.toml` | Конфигурация Android-сборки, SigningConfigs, разрешения | `INTERNET`, `ACCESS_NETWORK_STATE`, `RECORD_AUDIO`, зависимости Firebase/Compose/Credentials | Сохраняются в корне; дополняются поддержкой `jniLibs` и интеграцией `librustgram_bridge.so` |
| `app/src/test/java/com/example/*` | Тесты (`ExampleUnitTest`, `ExampleRobolectricTest`, `MessagingRepositoryRuleTest`) | Проверка строк, пресетов ботов, ресурсов, правил Firestore | Расширяются интеграционными тестами Kotlin <-> Rust JNI Bridge |
